# Sakuflemon

Site et modpack du serveur Cobblemon Sakuflemon.

- `index.html`, `installer.html`, … : le site (GitHub Pages).
- `assets/config.js` : adresse du serveur, version, lien de l'instance Prism.
- `pack/` : le modpack packwiz, lu par Prism à chaque lancement (`pack/pack.toml`).
- `downloads/` : l'instance Prism à importer.
